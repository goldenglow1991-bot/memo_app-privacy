# memo_app-privacy

「ウィジェットメモ」アプリ([memo_app_Android](https://github.com/goldenglow1991-bot/memo_app_Android))のプライバシーポリシーを公開するための静的サイトです。GitHub Pagesでホスティングし、Google Play ConsoleのプライバシーポリシーURLとして使用します。

公開URL: https://goldenglow1991-bot.github.io/memo_app-privacy/privacy_policy.html

## 更新方法

`privacy_policy.html` を編集し、コミット・pushするだけで公開ページに反映されます。内容を変更した場合はアプリ側リポジトリ([memo_app_Android](https://github.com/goldenglow1991-bot/memo_app_Android))の同名ファイルも同期してください。
